# 电子价签 · 使用说明

这是一块 **4.2 寸黑白红三色墨水屏电子价签**，会自己显示日历（公历 + 农历 + 干支 + 生肖）、
当天的天气和温度、以及你所在的城市名。它靠**蓝牙**跟电脑说话 —— 电脑负责查天气、
对时间，再把结果发给价签。

---

## 一、你需要准备什么

| 需要 | 说明 |
|---|---|
| 一台电脑 | Windows 10/11、macOS、Linux 都行，**必须带蓝牙**（笔记本基本都有；台式机要插个蓝牙适配器） |
| 电脑联网 | 查天气要用 |
| Python 3 | 免费软件，[官网下载](https://www.python.org/downloads/)。**Windows 安装时务必勾上最下面那个 "Add python.exe to PATH"** |
| 价签上电 | 装上电池（或插上供电），屏幕上会显示日历 |

> 只有第一次要装 Python，以后都不用。

---

## 二、怎么用（三步）

1. **双击**对应你系统的启动文件：

   | 你的系统 | 双击这个 |
   |---|---|
   | Windows | `启动-windows.bat` |
   | macOS | `启动-mac.command` |
   | Linux | 终端里跑 `bash 启动-linux.sh` |

2. **第一次运行**会花 30 秒左右准备环境（只做这一次），然后开始找价签。
   看到 `找到价签 …` 就是连上了 —— 这时价签会整屏闪一下（约 16 秒），
   闪完屏幕上就是最新的日期、天气和温度了。

3. **那个窗口别关**（可以最小化）。关了就等于基站停止工作。

### 第一次运行可能会被系统拦一下

- **macOS**：会弹「"终端"想使用蓝牙」→ 必须点 **好**。
  点错了就去 `系统设置 → 隐私与安全性 → 蓝牙`，把「终端」打开。
- **Windows**：一般不用管；如果找不到价签，先确认 `设置 → 蓝牙` 是开着的。
- **macOS 如果双击没反应**：右键 → 打开（第一次会问"是否打开"，点是）。
- **Linux**：蓝牙服务要开着（`systemctl status bluetooth`），
  用普通用户跑的话可能要先 `sudo usermod -aG bluetooth $USER` 然后重新登录。

## 三、想改点什么，改 `配置.json`

用记事本（Windows）或文本编辑（macOS）打开 `配置.json`，改完保存，重新双击启动。

| 字段 | 作用 |
|---|---|
| `城市名` | 显示在温度后面那几个字（只能用常见汉字） |
| `纬度` / `经度` | 天气按这个坐标取。不知道就地图上右键查一下 |
| `纪念日` | 比如 `"10-05=生日快乐！"` —— 那天会在日历上套黑框并写出这句话；不想用就留空 |
| `和风key` | 见下面「想要更准的天气」 |

> 带「_」开头的行是说明，不用管。

### 想要更准的天气 + 暴雨提醒（可选）

默认的天气源是 **Open-Meteo**（免费、不用注册），它给的是**气象模型值**，
跟你手机上看到的有时候会差 2~3℃，而且**没有预警信息**。

想更贴近手机（实况值）并且能看到「暴雨」「雷电」这类**官方预警**，
去 [dev.qweather.com](https://dev.qweather.com) 免费注册一个和风天气账号，
然后在 `配置.json` 里填两项：

```json
"和风key": "你的key",
"和风API Host": "控制台「设置」里给你的那串"
```

个人免费额度是 **5 万次/月**，这里一天只查几十次，用不完。

## 四、常见问题

**找不到价签？**
确认价签上电了（屏幕上有日历）。如果它刚换过电池，**碰一下它上面的复位点**再等一会儿。
还不行就把这个窗口关掉，重新双击一次。

**天气没变 / 时间停在某一刻？**
正常。为了省电，价签只在「有变化」的时候重画：天气每 30 分钟查一次，
没变就不刷屏。所以屏幕上那个时间不一定是"现在"。

**电脑关机了会怎样？**
价签会保持最后收到的内容。它自己还在走时间，但你关机的这段时间里
天气和温度不会更新。**开机后再双击一次启动**就恢复。

**屏幕闪得慢？**
墨水屏整屏刷新本来就是 **16 秒左右**，这是屏的物理特性，不是卡住了。

**能同时管两块价签吗？**
现在只能管一块（程序只连第一块找到的）。

## 五、给想折腾的人

启动脚本其实就是跑这一条命令：

```bash
python3 zk_ble_base.py watch --config kit/配置.json
```

命令行参数会覆盖 `配置.json`，比如：

```bash
python3 zk_ble_base.py watch --config kit/配置.json --city 北京 --lat 39.9042 --lon 116.4074
```

其它用法（`probe` 只看能不能找到、`sync` 只同步一次）见 `zk_ble_base.py` 开头的注释。
